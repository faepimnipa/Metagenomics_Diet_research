
# LIFE750 Cycle 1 Poster: Metagenomic Analysis of Microbiomes

## Project Description
This repository contains the data outputs and visualization reports for our LIFE750 Cycle 1 Team Poster assignment. The project focuses on a bioinformatics workflow to compare the gut microbiome composition of individuals on Western and Korean diets (specifically focusing on high weight loss samples) using shotgun metagenomics data.

## Dataset
The dataset consists of human faecal samples sourced from the EBI Metagenomics database (Study Accession: MGYS00000394 / ERP005558), as provided in the module workshop.

## Bioinformatics Workflow
Our team implemented the following pipeline to process and analyze the raw sequencing data:
* **Quality Control:** FastQC was used to assess the sequence quality of the raw paired-end reads.
* **Taxonomic Profiling:** Kraken2 was utilized to classify the reads and generate taxonomic reports (`.kreport2` files).
* **Visualisation:** Pavian (an R-based interactive tool) was used to compare taxonomic abundance across multiple samples and generate the final visual output.

## Repository Contents
* `*.kreport2` files: Taxonomic classification reports generated by Kraken2 for each sample.
* `report.html`: The interactive Pavian visualization report used for biological interpretation and generating poster figures.
